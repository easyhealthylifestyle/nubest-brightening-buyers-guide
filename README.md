# Label Check: How to Choose a Skin Brightening Supplement

A one-page guide that helps readers judge a skin brightening supplement by its label before reading reviews. It includes an interactive ten-point label checklist, plain-language notes on common ingredients, the daily habits that matter most, and a worked example using NuBest White.

**Live site:** https://easyhealthylifestyle.github.io/nubest-brightening-buyers-guide/

Companion to NuBest’s article [Top 7 Best Skin Brightening Supplements](https://www.nubest.com/blogs/beauty-care/best-skin-brightening-supplements).

## What the page includes

- **Label checklist:** ten points across transparency, quality, safety and claims. Unticked points turn into questions to ask the brand.
- **Ingredients you’ll see often:** glutathione, vitamins C and E, alpha lipoic acid, collagen peptides, hyaluronic acid and niacinamide, described by what they are
- **Habits that matter more than any capsule:** sunscreen, diet, sleep, a steady routine and when to see a dermatologist
- **Worked example:** the facts NuBest publishes about NuBest White, laid out against the checklist
- **A note on injections:** why capsules and injectable skin products are not the same

## Deploy with GitHub Pages

1. Create a public repository named `nubest-brightening-buyers-guide` under `easyhealthylifestyle`.
2. Upload the four files to the root of the `main` branch.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save. The site will be live at `https://easyhealthylifestyle.github.io/nubest-brightening-buyers-guide/`.
